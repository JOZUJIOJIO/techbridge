THE CURATED EIGHT

01 · find-skills 推荐

Vercel Labs 的 Skill 搜索器。先缩小候选范围，再进入安全审计，而不是盲目安装排行榜。

02 · skill-supply-chain-audit 本期必装

Tech Bridge 原创。先知道一个 Skill 会做什么、读什么、传什么，再决定是否信任。

03 · skill-creator 高阶

Anthropic 的 Skill 创建与评估系统。适合把反复出现的工作流沉淀成可测试能力。

04 · frontend-design 推荐

Anthropic 的前端设计 Skill。先建立视觉命题和记忆点，再写页面，减少模板化 AI 设计。

05 · agent-browser 条件推荐

让 Agent 在真实浏览器里导航、点击、填表和测试。能力强，但必须管住会话、Cookie 和敏感操作权限。

06 · systematic-debugging 强烈推荐

不允许 Agent 在没有根因时连续猜测。先复现、收证据、提单一假设，再做最小验证。

07 · verification-before-completion 强烈推荐

任何“已完成”都必须对应一条刚刚运行过的验证证据，阻止 Agent 把推测写成结果。

08 · lark-base 中国业务场景

把 Agent 接入飞书客户、商机、订单、收入和 Workflow。价值高，但写外部数据前必须确认真实表结构和权限。

BUYER'S ORDER · 推荐顺序

先审计，再安装调试与验收底线；设计、浏览器和飞书能力只在真实任务需要时启用；工作流重复以后，最后再创建自己的 Skill。
